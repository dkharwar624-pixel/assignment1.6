I learned how to upload a local Git repository to GitHub. First, I created a GitHub account and created a new public repository named web-development-practice on the GitHub website. Then I opened the terminal in my local project folder and connected my local repository to the remote GitHub repository using the git remote add origin command with the repository URL. I renamed my local branch to main using git branch -M main and pushed all my local files to GitHub for the first time using git push -u origin main. After that, I added a new file, README.md, to my project, committed the changes, and pushed the second commit to GitHub using git push. Finally, I opened my GitHub repository in the browser and verified that all files were uploaded and the commit history was visible. This assignment helped me understand how GitHub works as a remote platform for storing and sharing code.
